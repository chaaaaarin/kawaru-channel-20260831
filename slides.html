11月までにやること ③ どうしても GPT が要るなら

  • OpenAI で自分用の API キー（利用の窓口）を作る

この件の教訓：1社に握られる怖さ

便利なツールでも、その中身（AIの頭脳）を1社に頼っていると、会社どうしの都合で、ある日いきなり使えなくなることがある。今回はそれが現実になりました。

今回の Cursor × GPT

買収 → 契約解除 → 11月で停止。使う側は待つしかない

だから大事なのは

「1つ止まっても、別の手が残っている」状態にしておくこと

教訓26

今日からできる

081社依存を減らす3つの習慣

モデルは2社は使える状態に

メインとは別に、もう1社をいつでも選べるようにしておく

指示文を1社に寄せすぎない

特定モデルの癖に最適化しすぎず、他でも通る書き方にする

定期的に手元に書き出す

大事なやり取り・設定・プロンプトは自分の手元にも残す

  • 「1社依存」の怖さは他ツールでも同じ
